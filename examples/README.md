# Examples: demo data and a reproducible worked example

Every output in this folder is regenerated by `scripts/reproduce.sh` from the datasets committed here,
with no network access and no repository clones. CI runs it and fails if anything changes.

## Dataset format

`absorption-meter export` writes a repository's mainline history as JSON lines (format
`absorption-meter/changes@1`); `absorption-meter analyze --input` reads it. A dataset stores only what the
measures need: change sizes and paths, whether a change looks like a fix, which commit it reverts,
release tags, and contract-drift findings. **It stores no author names, e-mail addresses or commit
messages,** so teams can share a history without sharing code or identities.

```bash
absorption-meter export path/to/repo --since 2025-01-01 -o my-team.jsonl
absorption-meter analyze --input my-team.jsonl
```

## `demo/`: a synthetic team

A fictional team: twelve steady months, then AI-assisted development from January 2025. Production
doubles, changes grow and touch more of the system, rework rises, two API changes break compatibility
without a version bump, and telemetry coverage slips. Every pair signals and the decision is **Hold**.

```bash
absorption-meter analyze --input examples/demo/changes.jsonl --team-metrics examples/demo/team.csv
```

Files: `make_demo.py` (deterministic generator), `changes.jsonl`, `team.csv`, `report.md`, `report.json`.

## `homebrew/`: a worked example on real data

The mainline history of [Homebrew/brew](https://github.com/Homebrew/brew), a public, PR-based project
with semantic-version releases, from July 2024 to October 2026 (4,176 changes). The dataset is pinned
to commit `3e47189a707c739ee1278a28a3b845f5834574e6`.

| File | Contents |
|---|---|
| `changes.jsonl` | The exported dataset |
| `report.md`, `report.json` | The report as of October 2026 |
| `monthly.csv` | Month-by-month measures (final values) |
| `rule_timeline.md`, `timeline.csv` | The decision rules replayed month by month, using only history available at the time |
| `robust/` | The same replay with the median/MAD baseline (`--robust`) |
| `ai_signals.csv`, `ai_files.csv` | Visible AI-assistance signals: AI co-author or agent commits per month, and when AI instruction files were added |
| `count_ai_signals.py` | Recomputes the AI signals from a checkout (counts only) |

**What it shows.** GitHub Copilot instructions were added on 24 July 2025. The replay returns **Hold** in
August 2025, the first month after, with rework and change cost rising; returns to **Scale** from
November 2025 to January 2026; flags change cost from March 2026; and returns **Hold** from May to July
2026, as size-weighted production roughly tripled while the absorption ratio (AR_repo) fell from about 0.8 to
0.5–0.7.

**What it doesn't show.** This is one project and an illustration of the method, not evidence that AI
caused the pattern. Visible AI signals mark only 2.7% of commits after adoption, autocomplete use leaves
no trace, and other changes happened in the same period. Read it as "here is what the rules would have
told the maintainers", not "AI did this".

**Reproduce from source.** Clone Homebrew/brew, check out the pinned commit, and run:

```bash
absorption-meter export path/to/brew --since 2024-07-01 --until 2026-11-01 \
  --source https://github.com/Homebrew/brew -o examples/homebrew/changes.jsonl
python examples/homebrew/count_ai_signals.py path/to/brew 3e47189a707c739ee1278a28a3b845f5834574e6
```
